Built, and still running.

A home lab and what has been built in it, a Prolog engine with an MCP server bolted to its side, a chat application that answers out of a folder you own and cites the paragraph, three games, and a library that takes text out of a PDF for good.

Prolog engine · C++, Kotlin · MCP

PI & piview

A Prolog interpreter written to be read as much as used, hand-written recursive-descent parser, a flat node stack, an indexed name/arity database, and no third-party dependencies at all. piview gives it two more faces: a live web view and an MCP server. A clause typed at the prompt, one asserted by an agent, and the listing in the browser are all the same database, changing under each other in real time.

Source

Cited retrieval · Kotlin, React · MCP

Seshat

A chat application over a private folder of text files. Ask it something and the answer comes back with the paragraph it was drawn from attached, open the citation and you are reading the text itself, not a summary of it. Retrieval is hybrid: BM25 keyword matching and dense embeddings, fused server-side by reciprocal rank fusion. One Kotlin jar is both the MCP server and the chat gateway.

Source

Java library · Maven Central

pdf-redaction

A redaction engine that actually redacts. The common tools draw a black rectangle over the text and ship a PDF whose content stream still contains every word underneath, copy, paste, and there it is. This one intercepts the text operators themselves, strips the characters while holding the visual layout together, and re-encodes any raster image overlapping a redaction zone with the pixels blacked out.

Source · Maven Central

Cave flyer · HTML5 canvas

G-Force X

A momentum-based cave navigator, and the most physical thing here. Thrust adds to velocity the way it does in Asteroids, and the cavern has two media, air pulls you down, water floats you up and thickens the drag, so the same input means two different things depending on where the ship is. The terrain is cellular automata, flood-filled so every pocket connects: if you can see it, you can fly to it.

Source

Vector arcade · three.js

Super Asteroids

Asteroids with the edges taken off. The ship is pinned to the centre of the view and the universe is translated around it, so there is no screen to wrap at, rocks spawn into a ring outside the viewport and are collected again further out, which keeps the field infinite while the live entity count stays flat. Vector line under a bloom pass, and every laser is pitched off the last so a firefight does not turn into one flat tone.

Source

Arcade · HTML5 canvas

Space Invaders

The 1978 cabinet, rebuilt in a canvas element with no framework and no build step, because the classic is a near-perfect specification, and the details are the whole game. Eleven columns by five rows, one shot on screen at a time, bunkers that erode block by block as they take fire, and a step interval scaled to the number still alive: nine tenths of a second with the formation full, a twentieth of a second with one left.

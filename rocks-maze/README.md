# Rock's Maze

An AI generated game using `opencode`.  See `web_game.md` for a description.
This generated the `development_plan.md` file using the prompt:

```
@web_game.md this file contains a description of a game I want you to write.  
Please create a detailed development plan, 
breaking down the entier process into smaller tasks with descriptions.  
Then, save this plan into a markdown file.
```

The game required one fix after the first generation, also dealt with through `opencode`.

Visit <a href="https://peter.nz/rocks-maze/" target="_blank">Rock's Maze</a> for a live version of the game.
